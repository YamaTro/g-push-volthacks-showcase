# Contribution model

Contribution Score is a permanent record of accepted compute contribution. It
is not buyable, transferable, spendable, or money.

The important boundary is **accepted work**: rejected, duplicate, abandoned,
or unverified attempts do not increase the record. This is separate from GP,
which is an internal compute-utility concept. This showcase does not claim GP
purchase, cash-out, peer-to-peer transfer, or public Production activation.
